# Cold start performance findings

This report records historical measurements. The one-hour verification sweep requirement was removed on October 18. See the [current verification policy and measurements](feed-verification-performance-2026-10-18.md).

Reviewed October 17, 2026. Implementation details use the installed Next.js 16.4.1 [package](../../node_modules/next/package.json).

Electron recommends profiling the running application, deferring expensive setup, avoiding unnecessary module loading, and asynchronous main-process I/O. These recommendations support measurement before changing concurrency or adding caches. [Electron performance guidance](https://www.electronjs.org/docs/latest/tutorial/performance).

Artifact validation now runs file containment checks, metadata reads, and streaming SHA-256 checks through four workers. Directory containment still precedes traversal. A failed worker stops workers from taking new files. Validation waits for active workers before returning.
